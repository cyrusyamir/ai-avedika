# Comprehensive Data Structures & Algorithms (DSA) Roadmap
**Target Audience**: Absolute Beginner  
**Methodology**: Concept First (Abdul Bari) ➔ Code Realization (NeetCode)  
**Daily Commitment**: 3 Hours Total (1 Hour Theory/Conceptual Study + 2 Hours Hands-on Code Practice)

---

## Phase 1: Conceptual Foundations & Time Complexity
*   **Timeframe**: Week 1 (7 Days)  
*   **Daily Breakup**: 1 Hr Conceptual Video + 2 Hrs Code Tracing & Manual Complexity Analysis  

### Topics to Master
*   What is an Algorithm? (Inputs, Outputs, Correctness)
*   Asymptotic Notations: Big O ($O$), Omega ($\Omega$), Theta ($\theta$)
*   Analyzing Loops: Linear $O(N)$, Nested $O(N^2)$, and Logarithmic $O(\log N)$ scaling
*   Memory Space Complexity: Constant space $O(1)$ vs. Linear space $O(N)$

### Learning & Practice Resources
*   [Abdul Bari: Unit 1 - Analysis of Algorithms](https://youtube.com)
*   [NeetCode: Big-O Notation Guide](https://neetcode.io)

---

## Phase 2: Linear Data Structures (Static Memory)
*   **Timeframe**: Weeks 2–3 (14 Days)  
*   **Daily Breakup**: 1 Hr Structural Theory + 2 Hrs Implementation & Array Puzzle Manipulation  

### Topics to Master
*   Contiguous Memory Arrays: Static vs. Dynamic Array Allocations
*   Array Mechanics: Hidden time costs ($O(N)$) of inserting/deleting elements at index 0
*   The Two-Pointer Technique (Scanning arrays from opposing boundaries)
*   Sliding Window Basics (Tracking a running sub-segment of an array)

### Learning & Practice Resources
*   [Abdul Bari: Arrays & Matrix Representations](https://abdulbari.in)
*   [NeetCode 150: Arrays & Hashing Tracking Map](https://neetcode.io)
*   [NeetCode Beginner Plan: Array Lessons](https://neetcode.io)

## Phase 3: Fluid & Restricted Linear Structures (Dynamic Memory)
*   **Timeframe**: Weeks 4–6 (21 Days)  
*   **Daily Breakup**: 1 Hr Manual Pointer/Reference Logic + 2 Hrs Reconstructing Low-Level Nodes  

### Topics to Master
*   Linked Lists: Single, Double, and Circular memory structures
*   Pointer/Reference Manipulation: Safely changing node addresses without breaking memory chains
*   Stacks (LIFO): Last-In, First-Out arrays; push, pop, and peek functions
*   Queues (FIFO): First-In, First-Out structural buffers

### Learning & Practice Resources

## Phase 4: Recursion, Divide-and-Conquer & Searching
*   **Timeframe**: Weeks 7–9 (21 Days)  
*   **Daily Breakup**: 1 Hr Call-Stack Dry-Running + 2 Hrs Writing Recursive Code Functions  

### Topics to Master
*   Recursion Fundamentals: Base Cases vs. Recursive Steps
*   The Call Stack: How system memory processes suspended recursive functions
*   Binary Search: Executing Logarithmic ($O(\log N)$) item lookups on pre-sorted arrays
*   Divide-and-Conquer Sorting: Merge Sort and Quick Sort step-by-step algorithms

## Phase 6: Graph Networks & Optimization Strategies
*   **Timeframe**: Weeks 13–16 (28 Days)  
*   **Daily Breakup**: 1 Hr Theoretical Architecture Study + 2 Hrs Coding Network Matrices & Memoization Tables

## Low-Level Rules for Beginner Practice
1.  **Paper Tracing First**: Spend the first 20 minutes of your practice hours drawing the problem out with a pen and paper. If you can't trace the data flow manually, do not try to write the code.
2.  **No Native Helpers**: Do not use system shorthand functions (like Python's `.sort()`, Java's `Arrays.sort()`, or JavaScript's `.shift()`) during your first 8 weeks. Write out the pointer changes and loop arrays manually to build your core coding foundation.
